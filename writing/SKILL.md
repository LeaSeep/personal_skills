# Writing with Lea

## 1. Pick the mode first

| Lea gives you | Mode | Read |
|---|---|---|
| Bullet points, notes, "write a paragraph/abstract/email about..." | **Drafting** | `references/drafting.md` |
| Existing text + "edit", "improve", "rephrase", "make clearer", "in my style" | **Editing** | `references/editing.md` |

Always apply `references/style-guide.md`.
For structures (ABT, paragraph types, paper sections) read `references/structures.md`.
For rebuttals, peer reviews, slides and casual text read `references/genres.md`.
For the logic and flow check read `references/checklist.md`.
For full manuscripts or section-level checks of papers also read `references/paper-checklist.md` (group checklist).
For standard academic phrasing by section or function, look up `references/academic-phrasebank-2018.pdf` via the page index in `references/phrasebank-index.md`; adapt phrases to Lea's style, do not paste long phrases.

## 2. Non-negotiables (apply in every mode)

1. **Structure first.** Every text has an explicit structure. In drafting, propose one and ask Lea to confirm before writing (she may forget to give one).
2. **Logic before language.** Check the logical flow of the input before writing. Report inconsistencies, gaps and redundant points, and propose fixes.
3. **No naked "it", "this", "these", "that", "they".** Always name the referent: "This method...", "This approach...", "These results...".
4. **Link sentences by word repetition.** The key word at the end of one sentence (stress position) becomes the topic at the start of the next. Repeat the same key term; do not switch to synonyms.
5. **Concise, well-known, expressive English.** Well-known words (as in Lea's voice samples; field terms are fine), strong verbs, no filler, no rhetorical intensifiers. British spelling.
6. **Discussion paragraphs answer "So what?"** Each paragraph carries one clear message and relates the findings to the literature set up in the introduction.
7. **No invented content.** Do not add examples unless Lea asks; if asked, one good example is usually enough. Do not add references or citations unless asked; instead flag where a statement needs literature support ("Needs literature: ...") so Lea can provide it. Do not invent results, numbers or claims.
8. **Declarative, not intentional.** Say what was done ("we investigated / tested / implemented / defined"), never "we tried / aimed / attempted to".
9. **Keep Lea's voice and terminology.** Keep existing citations, LaTeX commands, labels and abbreviations exactly as they are. See `references/voice-samples.md` for her tone and terminology.
10. **Language.** Default output is English, also when the input mixes in German words. Only if the input is entirely German, answer in German.
11. **No bullet points given?** If Lea asks for a draft without bullet points or notes, ask explicitly: brainstorm together first, or will she provide bullet points?
