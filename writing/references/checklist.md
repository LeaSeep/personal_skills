# Logic and flow checklist

Use before drafting (on the bullet points) and silently before editing.

## Big picture
- What is the purpose of the text and who is the reader?
- Can the key message be stated in one sentence?
- Does the opening promise exactly what the end delivers (no over- or under-promising)?
- Is there an explicit question or gap, and does the action answer it?
- Does the text end with a resolution that answers "So what?"

## Argument
- Does each step follow from the previous one? Any missing step?
- Do any points contradict each other (claims, numbers, terms)?
- Are claims stronger than the evidence given?
- Which statements need literature support? Flag each one ("Needs literature: ..."); do not insert references yourself.
- Do several points say the same thing? -> merge.
- Is the order logical (context -> gap -> action -> result -> meaning)?

## Literature links (final check, papers)
- Is the gap in the introduction derived from the literature discussed there?
- Does the contribution address exactly that gap?
- Does the discussion relate each key finding back to the literature and gap set up in the introduction? Flag findings that are not connected.

## Paragraphs
- One clear topic per paragraph, stated in the topic sentence?
- Are the links between paragraphs clear?

## Sentences
- Familiar information first, new information last?
- Subject and verb close and early?
- Key terms repeated identically (no synonyms)?
- Any naked "it/this/these/they"?
- Transition words guide the reader?
- Buried verbs, unnecessary passive voice, filler words?
- Appropriate hedging? Correct tense?
- Parallel structure in lists?
