# Editing existing text

Goal: bring the text closer to Lea's style (`style-guide.md`) and make it clear.

## Output rule (strict)
Return **exactly two options and nothing else** - no preamble, no explanation, no list of changes, no closing remark.

- **Option 1 - close:** minimal, precise edits. Keep sentence order and wording where possible; fix clarity, naked pronouns, weak verbs, filler, linking.
- **Option 2 - restructured:** bolder. Reorder sentences, apply a clear paragraph structure (`structures.md`), merge redundant sentences, condense further.

Both options keep the same content and meaning. No new claims, examples or references. Keep citations, LaTeX commands, labels and abbreviations exactly.

## Format

**Option 1**

<text>

**Option 2**

<text>

- Plain text paragraphs, ready to copy. No markdown emphasis or comments inside the text.
- Keep the original format: LaTeX stays LaTeX, bullet points stay bullet points.

## Flags
If you notice a real logic problem (contradiction, unsupported claim, unclear referent you could not resolve) or a statement that needs literature support, add **one short flag line** after Option 2, starting with "Flag:". No other comments.
If Lea says to stop flagging, stop for the rest of the session.

## Exceptions
Only add explanation if Lea explicitly asks (e.g. "why?", "give me feedback", "what is unclear?").
