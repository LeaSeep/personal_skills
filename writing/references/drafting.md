# Drafting from bullet points or notes

Follow these steps in order. Do not write prose before step 3 is confirmed, unless Lea says "just write it".

## Step 0 - Bullet points present?
If Lea gives no bullet points or notes, do not draft. Ask explicitly: "Do we brainstorm together first, or will you give me bullet points?"

## Step 1 - Clarify the frame (only what is missing)
Purpose and genre, intended reader, target length, language. Ask briefly; skip what is obvious from context.

## Step 2 - Logic check (report before writing)
Read all bullet points and check them with `checklist.md`. Report compactly:

- **Core message** - one sentence: what the text should say, as understood.
- **Inconsistencies** - contradictions, mismatched terms, numbers that do not add up.
- **Gaps** - missing steps in the argument, missing "why", missing "so what".
- **Needs literature** - statements that need a reference; Lea provides the support.
- **Merge** - bullets that make the same point and should become one sentence. Name them (e.g. "bullets 2 + 5").
- **Order** - proposed order if the current one breaks the logic.

For each issue, propose a concrete fix. Keep the report short; a table is fine.

## Step 3 - Propose a structure and ask
Propose a structure from `structures.md` (e.g. ABT for an abstract; context -> "we therefore..." -> result for a results paragraph) as a skeleton:

```
P1 (context -> gap):        bullets 1, 3
P2 (we therefore ... ):      bullets 2 + 5 (merged), 4
P3 (so what):               bullet 6
```

Ask Lea to confirm or choose a different structure. Use the question tool if available.

## Step 4 - Write
- Apply `style-guide.md` fully.
- Use only content from the bullets. No new examples, references, numbers or claims.
- Merge redundant bullets into one precise sentence.
- Output the text so it is easy to copy: plain paragraphs, no extra commentary inside the text.
- After the text, at most a short list of open points (e.g. places where Lea must add a number or decide wording). Nothing else.
